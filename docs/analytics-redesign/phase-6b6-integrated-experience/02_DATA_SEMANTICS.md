# 資料語意

Hub 的「統計使用說明」只保留管理者需要的四句，不貼 Metric Contract。

- 中心營運：預約筆數與不重複學生數不同。名額是座位合計，預約是預約列。時間用活動日期。
- BESTEP：畫面上的既有通過率尚未核准，不是官方達標率。計算仍是既有 `passedCount / registeredCount`，150% 不會被夾限。出席 `true` 是出席、`false` 是缺席、`null` 或缺欄是未確認、空物件是未匯入。分數 0 顯示 0，空值顯示 `-`。
- 學習參與：資源接觸的人數是不重複學生數，事件次數是另一欄。接觸、事件與能力變化都不是已確認的因果效果。`causalClaimAllowed` 仍為 false。準因果陣列不渲染。
- 三個領域的比例分母不同，不能放在一起比較，也不能把活動日、班級學期與分析快照合成一個篩選。

資料品質卡仍是說明，不是分數。保留的產品語句是：未知出席不是缺席或零分、總分 0 與缺值與未匯入不同、三個 Shadow 預設關閉、通過率與調整後成長尚未核定。決策代號沒有印在每張卡片上。

本階段沒有改 loading、錯誤與空狀態的既有行為。既有測試仍通過：營運頁換學期會清掉上一組數字；資源頁載入時先清資料；錯誤是警示，不是假的比率；空陣列不能解讀成沒有學習。沒有改後端 SQL。
