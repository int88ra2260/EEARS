# 尚待主管確認的統計政策

以下都還沒有核准。文件裡的試算不是政策。

1. 班級頁的「四科通過率」要衡量成功報名本國生、全部本國生，還是有完整四科成績的人。
2. 這個數字是否繼續和現在的 Legacy 並存。若並存，名稱必須分開，不能都叫通過率。
3. 核准抵免是否算四科通過、從母體排除，或只留在分母。試算採用「不算通過」。
4. 只有團體報名、沒有成功個人報名的人是否進入母體。現行程式不因此增加分母。
5. 分母為 0 時，對外顯示無法計算還是 0%。候選試算使用無法計算；Legacy 仍是 0%。
6. 缺一科或完全沒有成績的人，在選項 A、B 是否留在分母。
7. 此決策不得直接改寫學習成效 KPI 的 B2 達標定義。KPI 仍走 `et_exam_attempts`。

F-BESTEP-01 在上述決定前保持 `decision_pending`。F-BESTEP-02 不依賴這些決定。
