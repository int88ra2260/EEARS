# 下一階段準備

出席顯示的程式與元件測試已完成，可以在下一次部署窗口一併上線。上線前仍要看實際表格，因為這次沒有瀏覽器驗收。匯出檔不會跟著變成「未確認」。

通過率公式還沒有實作條件。需要主管先從 A、B、C 選一個母體，並寫下抵免、團體報名與分母為 0 的規則。選定後的實作要同時改卡片、匯出摘要與欄位契約，並保留 50%、150% 與分母為 0 的合成案例，證明新定義與 Legacy 的差異仍可解釋。

L3 仍是前提：同一學生多筆成績哪一列留下、名冊是否一人一列，都會影響任何新分母。在 L3 與政策核准之前，不改 `passRate`。

不建議下一階段繼續擴充 Shadow，也不建議新做 BESTEP Dashboard。
