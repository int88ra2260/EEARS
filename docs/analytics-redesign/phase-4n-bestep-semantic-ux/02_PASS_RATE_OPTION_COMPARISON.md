# Legacy 與三種候選定義

數值來自 `tests/bestepClassPassRateDecision.test.js`。該檔呼叫正式的 `computeClassBestepExportSummary`，再用與 service 相同的兩行計算 Legacy 通過率。選項 A、B、C 的函式只存在於這個測試，service 原始碼沒有這些函式。

成績來源是該查詢學期的 `bestep_exam_scores`。報名來源是同一學期最新一筆 `EnglishTestRegistration`。本國生來自該學期 `EtEnrollmentSnapshot`。出席未知不進入任一通過率。沒有合併多個成績來源，也沒有改用歷史最佳技能。

| 項目 | Legacy | 選項 A | 選項 B | 選項 C |
|---|---|---|---|---|
| 管理問題 | 沒有單一母體 | 成功報名的本國生通過了多少 | 班級本國生通過了多少 | 四科等級齊全的人通過了多少 |
| 分子 | 全部名冊中 `score.passed` 為真 | 成功報名本國生且 `score.passed` | 本國生且 `score.passed` | 四科 CEFR 齊全且 `score.passed` |
| 分母 | `registeredCount` | 成功報名本國生人數 | 本國生人數 | 四科 CEFR 都在 A1–C2 的人數 |
| 母體 | 分子與分母不同 | 同一群成功報名本國生 | 同一群本國生 | 同一群完整成績者 |
| 缺成績 | 不進分子；若是成功報名本國生仍在分母 | 留在分母 | 留在分母 | 排除 |
| 未知出席 | 不影響 | 不影響 | 不影響 | 不影響 |
| 抵免 | 不自動算通過；成功報名仍在分母 | 試算相同，政策未決 | 試算相同，政策未決 | 沒有四科等級就排除；政策未決 |
| 學期 | 查詢學期的名冊、報名與成績 | 同左 | 同左 | 同左，只用該列四科 |
| 來源 | `bestep_exam_scores` 加報名與名冊 | 同左 | 同左 | 同左的四科等級欄 |
| 選擇偏差 | 分子比分母更寬 | 未報名者不在內 | 未測者拉低比率 | 只留有完整成績的人 |
| 現有資料 | 已在正式公式使用 | 報名狀態與本國旗標已有 | 本國旗標與 `score.passed` 已有 | 四科等級已在成績列；重複列以哪一筆為準仍是 L3 |
| 是否等於 KPI | 否 | 否 | 否 | 否 |
| 仍需核准 | 要不要停用 | 抵免、團體報名、分母 0 | 未測者是否留在分母、抵免 | 「有效成績」是否等於四個 CEFR 欄都有值 |

混合班試算：Legacy 100%（4/4），A 25%（1/4），B 42.86%（3/7），C 80%（4/5）。

母體一致時四種都是 50%。Legacy 150% 時，A 是 50%，B 是 66.67%，C 是 75%。只有非本國通過者時，Legacy 顯示 0%，A 與 B 是無法計算，C 是 100%。

缺一科的本國成功報名者留在 Legacy 與 A 的分母，不進入 C。報名失敗與未報名但有通過成績的人進入 Legacy 分子，不進入 A 的分子。
