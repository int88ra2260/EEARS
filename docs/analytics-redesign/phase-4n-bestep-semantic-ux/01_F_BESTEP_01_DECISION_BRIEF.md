# 班級 BESTEP 四科通過率決策摘要

這份說明給中心主管比較用途。工程沒有選定正式定義，Finding 仍是 `decision_pending`。三個選項不是同一個指標的三種寫法，也不能稱為正式 B2 KPI。

## 目前 Legacy 定義

`buildClassBestepOverviewStatistics` 的現況是：

- 分子 `passedCount`：該班該查詢學期全部名冊列裡，`score.passed` 為真的列數。
- 分母 `registeredCount`：本國生，且最新一筆個人報名狀態是 `success` 或 `registered_success` 的人數。
- 分母為 0 時，公布的 `passRate` 被寫成 0。

`score.passed` 來自該學期 `bestep_exam_scores`。寫入時要四科 CEFR 都存在，且每一科至少是 B2。本國生資格來自該查詢學期的學習歷程名冊；名冊沒有這個人，或 `isDomestic` 明確為 false，就不算本國生。

已用合成資料確認：分子可以包含報名失敗、未報名與非本國生。因此通過率可以是 150%。分母為 0 而分子大於 0 時，畫面數字是 0%，不是無法計算。

## 三個候選，都尚未核准

- 選項 A：成功報名的本國生通過率。回答「報名成功的本國生裡，有多少人這次四科通過」。
- 選項 B：班級本國生通過率。回答「班級本國生裡，有多少人有一筆通過的四科成績」，未參加的人留在分母。
- 選項 C：有完整四科 CEFR 的人通過率。回答「這次檔案裡四科等級都齊的人，有多少人全部達 B2」。缺少任何一科的人排除。

試算假設，尚未核准：核准抵免不會自動變成四科通過。候選公式在分母為 0 時給 `null`，表示無法計算，不顯示 0%。

## 同一批合成學生

八種人：本國成功且通過、本國成功但未通過、本國成功但缺一科、本國報名失敗且通過、非本國成功且通過、本國未報名但有通過成績、本國成功且有核准抵免但沒有四科成績、本國沒有報名也沒有成績。

| 定義 | 分子 | 分母 | 結果 |
|---|---|---|---|
| Legacy | 4 | 4 | 100% |
| 選項 A | 1 | 4 | 25% |
| 選項 B | 3 | 7 | 42.86% |
| 選項 C | 4 | 5 | 80% |

另外三個對照：

| 情境 | Legacy | A | B | C |
|---|---|---|---|---|
| 兩名本國成功報名，一人通過 | 50% | 50% | 50% | 50% |
| 分子混入報名失敗與非本國 | 150% | 50% | 66.67% | 75% |
| 只有一名非本國通過 | 0% | 無法計算 | 無法計算 | 100% |

150% 那一列的 Legacy 分子是 3、分母是 2。選項 A 只留兩名成功報名的本國生。選項 C 把四筆完整成績都留在分母。

## 各方案回答的問題

- Legacy 目前沒有回答單一管理問題，因為分子與分母不是同一群人。
- A 適合看報名行政與該次報名者的測驗結果。抵免生若報名成功，試算把他留在分母、不計入分子。
- B 適合看班級本國生覆蓋，不是「報名者的通過率」。
- C 適合看有完整成績的人表現。沒來考、成績不完整的人不會拉低比率，所以有選擇偏差。

## 與既有 KPI 的差異

學習成效 KPI 讀的是 `et_exam_attempts` 政策引擎，不是這頁的 `passRate`，也不是 `bestep_exam_scores`。班級頁不讀歷史最佳技能。`B2+` 在入檔時會存成 `B2`，不能還原。因此這三個選項都不能直接當成正式 B2 KPI。

## 主管需要決定的事

1. 「班級 BESTEP 四科通過率」要採用 A、B、C，或維持 Legacy 並改標名稱。
2. 核准抵免算通過、排除在母體外，還是只留在分母。
3. 團體報名沒有成功的個人報名時，要不要進入母體。現行程式不因為隊伍成員身分而增加 `registeredCount`。
4. 分母為 0 時顯示「無法計算」，還是繼續顯示 0%。
5. 缺成績的人在 A 或 B 是否留在分母。

## 決策之後才做的實作

選定後才一起改統計、卡片、匯出摘要與欄位契約，並用同一套合成案例驗收。在那之前不改公式。部署與正式驗收另計，不因為這份文件存在而視為已核准。
