# 產品方向

英語中心的管理者要先回答營運與資料是否可信，再看測驗與學習接觸。這次不新增圖表套件，也不把現有頁面重寫。

管理者要能分開四件事：

1. 中心這個學期提供了多少活動、被預約與出席多少。
2. BESTEP 的報名、到考與四技能結果，以及哪些數字還不能當官方達標率。
3. 學生接觸了哪些資源、有沒有可觀察的前後紀錄。這只能當探索，不能說是活動造成的進步。
4. 哪些欄位是未知、缺失或尚未核准。

`/admin/analytics` 目前沒有自己的首頁。現有入口是 `/admin/analytics/overview`。下一個實作階段應加一個導覽首頁，連到既有頁，而不是新的統計 API。
