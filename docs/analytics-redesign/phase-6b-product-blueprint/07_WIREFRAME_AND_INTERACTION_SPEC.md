# 畫面與互動

下一個可做的畫面只有 Hub 首頁。桌面寬度以現有後台內容區為準。

區塊由上到下：

1. 標題「分析」與一句限制：「以下數字沿用既有頁面，通過率與學習成長尚未核定。」
2. 四張連結卡：營運、測驗、學習參與、資料限制。每張寫路由與需要的權限；沒權限的卡不渲染，後端仍會拒絕直接網址。
3. 資料限制卡用條列，不畫新圖：未知出席、總分 0、報名 B2 標記、來源未合併、Shadow 未啟用。
4. 空狀態沿用現有 `EmptyState`。載入與錯誤沿用各目標頁，Hub 本身不發統計 API。

互動：卡是連結，不是篩選器。學期篩選留在各目標頁，避免一個下拉同時代表活動日與檔案學期。

鍵盤：連結可聚焦。對比沿用後台現有文字色，不在這次另做圖表。

不要在這張首頁放通過率、成長箭頭或新的 KPI 公式。
