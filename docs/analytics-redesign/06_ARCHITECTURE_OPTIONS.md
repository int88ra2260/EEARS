# 06 架構方案

三案都必須保住盤點到的業務問題，不要求保住每一支 API。

必須繼續回答的問題（來自現有資產，不是新願望）：

- 這一季活動與名額用得怎樣（S1）。
- 這次培力誰報名、誰到、四項等級如何、班級怎樣（S2、S3）。
- 學習有伴流程與「有伴者成績長什麼樣」（S4，含已寫明的非因果限制）。
- 這個學期名冊要交的達標人數（S6，但時間規則要改清楚後才算官方）。
- 誰接近門檻、某一個人的紀錄、系所差異（S7 的找人與比較）。
- 同一工具下前後兩次差多少、樣本夠不夠（S7 技能與資源）。
- 匯出與快照版本，用來核對而不是對外宣稱。

## Option A：依業務目的分層

四層：中心營運與方案、學生學習成效、關聯分析、共用治理。

| 面向 | 內容 |
|---|---|
| 主任／行政／教師 | 主任看方案層與達標層；行政進入某一層的工作頁；教師停在自己班級的方案與學習層，不進關聯層 |
| 容納現有資產 | S1→方案；S2／S5／S6／S7 能力頁→學習；S4 outcome 與資源成長→關聯；快照版本與匯入紀錄→治理 |
| 資料來源 | 每層標「系統行為」或「匯入」，禁止一層裡默默混合 |
| 時間 | 方案層用日期學期與培力檔案學期；學習層用批次或「截至」；不強共用一個學期篩選器 |
| 口徑 | 治理層維護指標字典。達標只留一個對外定義，其餘改顯示名 |
| 擴充 | 新圖必須宣告所屬層與等級（描述／比較／縱向／關聯） |
| 品質 | 治理層是第一公民，不是設定頁附錄 |
| 碎片化 | 層級清楚，但關聯層容易再長出第二個儀表板 |
| 複雜度 | 中。主要是入口與命名，計算可暫留 |
| 遷移風險 | 低到中。使用者要重新學「達標在哪一層」 |
| 測試 | 每層契約測試：母體、時間、禁止跨層引用未標示的數字 |

## Option B：依分析工作流程

五段：監測、主題分析、批次比較、長期追蹤、專題報表。

| 面向 | 內容 |
|---|---|
| 主任 | 監測只放少數已凍結定義的數字；專題報表做出簡報 |
| 行政 | 主題分析處理活動、培力場次、有伴 |
| 教師 | 幾乎只使用「某一班／某一門」的主題頁 |
| 容納資產 | 現有頁可整頁搬進工作流，少改計算 |
| 時間 | 監測用「本報告期」；批次比較用一次考試；追蹤用個人觀測。三個時鐘都在，但是流程名稱，不是資料契約 |
| 口徑 | 工作流不自動保證口徑。若監測直接嵌現有 KPI，F-03 會原樣進入主任畫面 |
| 擴充 | 新專題容易再加一頁，與現況相同的碎片風險 |
| 品質 | 沒有獨立治理段的話，版本與追溯仍掛在各主題 |
| 碎片化 | 高。流程分頁會複製現在的選單 |
| 複雜度 | 低（搬入口）到高（若每個流程各寫篩選器） |
| 遷移風險 | 低。也最可能什麼都沒改，只換分類 |
| 測試 | 難：流程分類測不到分子分母 |

B 適合當作過渡導覽，不適合當作目標架構。

## Option C：混合（決策入口＋語意層＋獨立時間模型）

三個決策入口，底下共用一個語意層，時間模型與資料品質不屬於任何一個入口。

入口：

1. **本季營運**：只放系統行為與培力「這一檔」的描述（報名、出席、四項等級、班級、有伴漏斗）。
2. **這次要交的結果**：名冊 × 凍結後的達標規則 × **宣告過的嘗試範圍**（某次考試，或截至某日）。
3. **對照**：預設關閉。打開時必須選「哪次考試、參與算到考試日前或某窗、同一工具或已標示的 GSE」。學習有伴 outcome 是第一個住進來的對照，不是範本可以省略 caveat。

語意層：指標 id、分子、分母、時間種類、證據等級、禁止的句子。S5 若保留，id 不得再叫 B2+。

時間模型：日期學期、檔案學期、考試日、匯入時間、快照版本、觀測窗，六個欄位可同時存在，禁止用一個 `semester` 參數走全部 API。

品質：每次對外數字帶 `populationId`、`ruleId`、`asOf` 或 `snapshotVersion`。重建狀態可見。

| 面向 | 內容 |
|---|---|
| 主任 | 入口 2 的凍結數字＋入口 1 的本季描述。不看校正後成長 |
| 行政 | 入口 1 做場次；入口 2 做名冊差距名單（現有 gaps） |
| 教師 | 入口 1 的班級切片。個人軌跡從人開始，不從學期總圖開始 |
| 容納資產 | S1、S2、S3、S4 漏斗→入口 1。S6 與差距名單→入口 2。S4 outcome、技能成長、資源→入口 3。S5 降級為「截至今日的歷史最佳」，不與入口 2 並列。S7 探索與接近 B2 留在入口 2 的找人，或從入口 2 連到人 |
| 資料來源 | 入口 1 可以同時顯示行為與「該檔匯入」，但區塊標題分開。入口 2 只吃名冊與嘗試。入口 3 才允許 join |
| 時間 | 三入口三時鐘，語意層記錄對齊規則 |
| 口徑 | 對外「達標」只在入口 2。班級四項 B2 改名，例如「四項等級皆達 B2」 |
| 擴充 | 新分析先登記指標 id 與證據等級，再決定入口。沒登記不能進主任頁 |
| 品質 | 快照版本、匯入批、as-of 是入口 2／3 的必要參數 |
| 碎片化 | 新頁必須掛入口，否則沒有導覽。比 A 更硬 |
| 複雜度 | 高。語意層與嘗試範圍是真的規則變更，不只是選單 |
| 遷移風險 | 中高。KPI 數字在收斂嘗試範圍後會變，必須事先對主任說明 |
| 測試 | 高。同一學號在三入口的納入條件可各自斷言；禁止入口 1 讀 `causal_effect` |

## 比較矩陣

| 準則 | A 分層 | B 工作流 | C 混合 |
|---|---|---|---|
| 主任不會看到兩種 B2 | 中（靠命名） | 低 | 高（對外只留一個） |
| 保住場次簡報與班級作業 | 高 | 高 | 高 |
| 時間衝突被結構擋住 | 中 | 低 | 高 |
| 不把相關寫成因果 | 中 | 低 | 高（對照入口預設關） |
| 少改就能上線 | 高 | 最高 | 低 |
| 避免再碎片化 | 中 | 低 | 高 |
| 可測試 | 中 | 低 | 高 |
| 誤遷風險 | 低 | 低 | 中（數字會變，必須當變更管理） |

## 有條件的取捨

若下一階段只准動導覽、不准動數字：採用 B 的入口名稱，但書面仍以 C 的指標字典為準，避免把現有 KPI 標成「本季考試成果」。

若可以改查詢範圍與文案、仍不重寫快照：採用 C。這是後續藍圖的前提。

A 是 C 的說明方式（對主任解釋三層），不是實作切割。不要同時做三套選單。
