# 合成資料

班級識別是 `SYN-CLASS`，名稱是合成班。學生識別是 `SYN-N1-A` 到 `SYN-N1-H`，加上第二頁的 `SYN-N1-P2`。沒有 email，沒有正式學號。

| 識別 | 出席 | 其他 | 畫面 |
|---|---|---|---|
| SYN-N1-A | L/R/S/W 都是 true | 較長的合成系所名稱 | 四科都是出席 |
| SYN-N1-B | 四科都是 false | 成功報名 | 缺席 |
| SYN-N1-C | 四科都是 null | 成功報名 | 未確認，不是缺席 |
| SYN-N1-D | 四科物件沒有 attended | 成功報名 | 未確認，不是缺席 |
| SYN-N1-E | `{}` | 成功報名 | 未匯入 |
| SYN-N1-F | `{}` | 核准抵免顯示聽讀說寫 | 抵免欄保留原文，出席格是未匯入，不是出席 |
| SYN-N1-G | `{}` | 沒有報名物件 | 個人報名是未報名，出席格不是缺席 |
| SYN-N1-H | L 為 true | `totalScore: 0` | 總分顯示 0 |
| SYN-N1-P2 | L 為 true | 只在 page=2 回傳 | 第二頁仍看得到出席 |

統計卡片使用 API 回傳的固定數字，`passRate` 是 100。頁面沒有重算。這個 100 不是業務核准值。Legacy 150% 仍只存在後端合成測試。
