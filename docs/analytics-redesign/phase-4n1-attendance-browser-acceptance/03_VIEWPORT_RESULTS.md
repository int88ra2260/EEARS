同一份已載入的正式頁面切換尺寸。頁面 `scrollWidth - clientWidth` 都是 0。徽章文字沒有被自身裁切。`.table-responsive` 的 `overflow-x` 是 `auto`。

| Viewport | 頁面溢出 | 表格內容寬 | 可視寬 | 局部捲動 |
|---|---|---|---|---|
| Desktop 1440×900 | 0 | 1126 | 1126 | 內容未超出，容器仍是 auto |
| Laptop 1280×800 | 0 | 1126 | 1126 | 內容未超出 |
| Tablet 768×1024 | 0 | 686 | 686 | 內容未超出 |
| Mobile 390×844 | 0 | 602 | 308 | 已捲到表格右側，頁面寬度沒有增加 |
| Small mobile 375×667 | 0 | 602 | 293 | 已捲到表格右側，頁面寬度沒有增加 |

出席欄標題在五種尺寸都能捲進可視範圍。未確認徽章在每種尺寸都可見。
