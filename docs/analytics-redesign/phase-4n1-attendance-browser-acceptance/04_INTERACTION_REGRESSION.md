# 操作回歸

這些操作走真實的 `ClassBestepOverview`、篩選元件與 `useClassBestepOverview`。

- 分頁：下一頁請求 `page=2`，只留下 `SYN-N1-P2`；上一頁回到第一頁。
- 考試類型：選 LR 後，請求帶 `examType=LR` 且頁碼回到 1。表格仍顯示合成出席文字。
- 搜尋：輸入 `SYN-N1-H` 後，請求帶相同 search，其他學生列消失，總分仍是 0。
- 空資料：顯示「沒有找到符合條件的資料」，沒有缺席文字。
- 載入：在合成回應釋放前顯示「載入中...」，釋放後才出現學生。
- 錯誤：概況 API 回 500 時出現 alert，沒有學生列，也沒有缺席文字。現有 hook 把拋出的 Error 交給 `handleAPIError`，沒有把 HTTP body 再分類；這次只確認 alert 存在，沒有改錯誤文案。
- 匯出按鈕仍在畫面上。瀏覽器測試沒有點它，也沒有發出 `/export` 請求。匯出行為改由既有後端測試佐證，不把瀏覽器匯出標成通過。
