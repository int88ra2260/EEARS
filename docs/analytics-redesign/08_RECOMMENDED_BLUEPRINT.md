# 08 建議藍圖

這是概念架構，不是實作規格，也不是請開發立刻改 API。

## 為什麼是 Option C

盤點顯示問題不在缺頁，而在三種時鐘被一個「學期」和一個「達標」蓋住（F-02、F-03、F-04）。只改選單（Option B）不會擋住錯誤句子。只依組織分層（Option A）仍可能在「學習成效」層裡並排兩套 B2。

C 把**對外只能有一個達標**寫進入口，把行為與成績的 join 放到預設關閉的對照入口，並把時間種類抬成共用欄位。現有頁面多數可留在某個入口裡，直到規則改完再改計算。

## 概念架構

```text
入口
  本季營運     系統行為＋「這一檔」匯入的描述
  要交的結果   名冊 × 單一達標規則 × 宣告過的嘗試範圍
  對照         預設關；打開才 join，且必須帶限制句

共用
  指標字典     id、分子、分母、證據等級、禁止句
  時間模型     日期學期／檔案學期／考試日／匯入時間／快照版本／觀測窗
  人           學號；個人頁從任一口進入，不自成第四套母體
  品質         版本、重建狀態、權限造成的母體差異必須出現在數字旁
```

## 與現況的差異

| 現況 | 藍圖 |
|---|---|
| 學習成效選單按開發任務分成上呈、找人、看資源、比較 | 入口按時鐘。找人是「要交的結果」裡的名單，不是平行產品 |
| KPI 用全部 valid 嘗試 | 「要交的結果」必須選定批次或 as-of，否則不算官方數字 |
| 歷史最佳叫 B2+ 認證率 | 改為「截至某日、各技能歷史最佳達 B2」。不與官方達標並列 |
| 班級 `passed` 也叫達標 | 改顯示名為四項等級皆達 B2（加號已不可得） |
| 快照總覽與名冊率容易被看成同一學期 | 總覽屬於快照版本，標題帶版本，不帶假學期 |
| 資源效果欄名像因果 | 對照入口以外不可讀該欄；入口內沿用有伴 outcome 那種 caveat |
| 未掛載英檢路由仍在樹 | 不納入藍圖能力；確認無腳本後再封存（另案，本次不做） |

## 三個入口各回答什麼

**本季營運**回答：活動有沒有被用、這一檔培力誰來、班級與有伴流程如何。證據等級停在描述。跨檔比較只允許規則沒變的出席率、四項等級率，並註明加號已失。

**要交的結果**回答：這份名冊、這條規則、這一個嘗試範圍，多少人過、誰沒過、誰落在 GSE 51–58。這是主任與行政的共同定義。教師看到的是同一規則下自己的班，母體句要寫範圍。

**對照**回答：在寫明的窗裡，參與與否與分數差異是否同時出現。第一批內容就是現有有伴 outcome、技能前後梯、資源樣本數。不新增因果估計。

## 指標字典（最小集合）

正式對外前要有 id 的，至少：

| id | 一句話 | 現有對應 | 遷移時 |
|---|---|---|---|
| ops.activity.semester_range | 日期學期內的預約與簽到 | S1 | 保留 |
| bestep.file.attendance | 某一檔案學期的分項出席 | S2 | 保留；補「四項都到」前先標缺口 |
| bestep.file.four_skills_b2 | 四項等級皆 ≥ B2／報考 | S2 `passed` | 改名，不叫 KPI |
| bestep.file.registration_mix | 消息來源與年級 | S3 | 保留，不與分數混圖 |
| partner.funnel | 組隊轉換 | S4 | 保留 |
| partner.score_gap | 有成績者的分數差 | S4 outcome | 進對照，保留 caveat |
| roster.pair_pass | 成對門檻 | S6 | 收斂嘗試範圍後才是官方 |
| roster.best_skill_b2_asof | 截至某日的歷史最佳 | S5 | 改名，標 as-of |
| snapshot.coverage | 某版本的人數與考試覆蓋 | S7 總覽 | 保留 |
| snapshot.near_b2 | GSE 51–58 且未達 B2 | S7 | 保留，路由名可以後再改 |
| snapshot.skill_delta | 同一工具兩梯的 GSE 差 | S7 | 進對照 |
| person.timeline | 單學號紀錄 | LJ／探索 | 保留，不彙總成率 |

## 不做的事

不把所有歷史學期畫成一條可比的 B2 線。不把 GSE 校正成長放進主任首屏。不為了簡報缺的大題分數而在這份藍圖裡假裝已有欄位。不廢除學習歷程投影，直到「要交的結果」不再依賴它——目前 KPI 本來就不讀快照，班級頁也不讀，所以投影只服務快照族。

## 成功時長什麼樣

同一位主任在「要交的結果」只看到一個達標定義。班級頁的四項等級不會被拿去加進那個數字。活動頁沒有英檢率。任何成長或差距的句子都出現在「對照」，且看得到窗與限制。快照頁看得到版本。以上都可以用測試固定文案與查詢條件，而不必先重做圖表。
