# 本次改善

管理者可以從成效分析中心進入班級列表，再用該列既有的 BESTEP 按鈕打開該班頁。按鈕文案改為「查看 BESTEP 分析」，沒有第二顆按鈕，Hub 仍不組 `/bestep` 網址。

班級 BESTEP 頁新增「資料怎麼讀」：報名、出席四態、抵免、成績缺值、CEFR、學期與既有匯出。既有 `passRate` 照 API 顯示，標成尚未核准的統計口徑，不拿來下成效結論。150 不截成 100，分母為 0 時 API 回的 0 仍顯示 0。

明細裡，出席 `null` 與缺少 `attended` 顯示未確認，不再被看成缺席。總分與四技能分數 0 顯示 0。沒有成績列仍是未匯入，不是缺考。

公式、匯出 API、匯入、權限定義與資料庫都沒有改。本提交收斂這條班級 BESTEP 讀法。基準是 Phase 6B.3 commit `997a89d18f99ad618d47ac626fd5776a24026046`。
