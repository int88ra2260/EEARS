# 05 評估方法與證據強度

分類只用來檢查「這張圖能支持什麼句子」。不是建議中的資訊架構。

證據等級：

1. Descriptive：人數、比率、分布。
2. Comparative：兩群或兩期，規則相同才能比。
3. Longitudinal：同一人、同一工具、有先後觀測。
4. Associational：兩種事實一起出現。
5. Causal：在對照與假設下主張方案造成變化。目前**沒有**已掛載分析達到這一級。程式多處把 `causalClaimAllowed` 設為 false。

## A. 方案與資源

| ID | 分析 | 能支持的句子 | 不能支持的句子 | 等級 |
|---|---|---|---|---|
| A1 | 活動總覽、報表 | 某日期學期的供給、預約、簽到、違規 | 學生因此英語變好 | Descriptive。跨學期比速率可以，要比「成效」則證據不足 |
| A2 | 培力出席（班級） | 該學期該班各科出席 | 缺考原因的因果；簡報「四項都出席」是否已有獨立指標：PARTIAL（出席有 L/R/S/W/LR/SW，頁面是否聚合四項：未逐一對 UI） | Descriptive |
| A3 | 報名消息來源 | 報名者自填從何得知 | 消息來源導致報考或導致高分 | Descriptive |
| A4 | 學習有伴漏斗 | 組隊流程停在哪 | 學習增益 | Descriptive |
| A5 | 資源覆蓋、課／師／活動 | 快照裡某類曝光的人數與時數、可形成前後測的樣本數 | 資源有效所以能力上升 | Descriptive。若旁邊並列成長數字，讀者會滑向 Associational，頁面必須標樣本是「有兩次考試的子集」 |
| A6 | `resource_effect_estimates.causal_effect` | 模型存了一個數值欄 | 對外報告「因果效果」 | 欄名是 Causal 等級的詞；旗標預設不允許。呈現若只寫「資源成效」仍有誤讀風險（F-06） |

中心年度目標是否達成：KPI 頁是最接近「上呈定義」的入口，但分子時間寬於名冊學期（F-03），所以現在只能說「依政策、用該生既有有效嘗試，名冊中有多少人達標」，不能說「本學期考試的達標率」。

## B. 學生學習成效

| ID | 分析 | 能支持 | 不能支持 | 等級 |
|---|---|---|---|---|
| B1 | 班級四項皆 B2 | 該學期匯入列上，四個等級（加號已剝）都 ≥ B2 的人數／報考人數 | 聽讀成對或說寫成對達標；簡報級距 B2+ | Descriptive |
| B2 | KPI 成對 | 名冊學生是否曾有（或政策選中的）嘗試達到門檻 | 「114-2 這一場」除非政策已把嘗試限制在該場。選筆規則 PARTIAL | Comparative（對門檻），不是該場描述 |
| B3 | 歷史最佳技能率 | 名冊上的人，截至現在各技能最好一次是否 ≥ B2 | 該學期當時的水準；也不能叫 B2+ | 看似 Longitudinal 的彙總，實際是「截至查詢日的最佳」，會改寫歷史 |
| B4 | 快照 CEFR 分布 | 這一版快照裡等級分布 | 加號帶；與名冊率直接比較 | Descriptive |
| B5 | 接近 B2 | 誰未達 B2 且 GSE 在 51–58 | 他們「差一點就會過」的預測 | Descriptive 篩人 |
| B6 | 技能成長 | 同一套窗規則下，有兩梯的人 GSE 差多少；校正後是統計調整（`baseline_adjusted_simplified` 或回歸 v2） | 調整後成長＝課程效果 | Longitudinal（原始差，且僅有兩梯者）。校正後仍是 Associational／統計調整，不是 Causal |
| B7 | 學生探索、個人軌跡 | 一個人的紀錄是否齊 | 群體達標 | 個案，不是母體統計 |

能力「隨時間變化」只有 B6 在有兩次可合併觀測時成立。單次 BESTEP、只有學期沒有日、或只有歷史最佳，都不是變化。

## C. 行為與成績放在一起

| ID | 分析 | 實際做的事 | 等級 |
|---|---|---|---|
| C1 | 學習有伴 outcome | 同學期、有成績者，有伴減非有伴。文案已否定因果與自選偏誤 | Associational，且已自我限制 |
| C2 | 課／師／活動頁若同時給參與與成長 | 本次未逐欄確認是否並排因果句 | 預設最多 Associational。需打開頁面文案後才能升信心，標 PARTIAL |
| C3 | LVA 資源效果 | 估計值入表，宣告因果預設關 | 不可升到 Causal |

沒有全系統規則規定「只計算考前的參與」。因此任何「參加活動所以進步」的句子，現有頁面都不夠格。

## 四個詞必須分開

| 詞 | 現有證據 | 易混 |
|---|---|---|
| 活動參與 | 預約、簽到、組隊、出席列 | 不等於有在學 |
| 學習投入 | 時數、微學習面板、護照點數是否進快照：UNKNOWN | 不可把簽到數叫做投入 |
| 能力表現 | 某次分數、CEFR、GSE、成對門檻 | 不是成長 |
| 能力成長 | 僅兩梯差，或被誤用的「歷史最佳變化」 | 歷史最佳不是成長 |

## 名稱風險

- `causal_effect`、資源「成效」、校正後成長、總覽 note「認證通過率…達 B2+」：詞強於證據。
- 學習有伴 outcome 的 `caveat` 是目前少數把限制寫進 API 的例子，應視為以後文案的下限，而不是特例。
