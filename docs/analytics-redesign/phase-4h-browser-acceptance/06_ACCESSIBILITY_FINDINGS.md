# 無障礙驗證

鍵盤與 ARIA 在真實 Chromium 通過，沒有因此修改頁面。

## 鍵盤

從學期選單 Tab 到「重新整理」，再 Tab 到五個指標說明按鈕。每個按鈕：

- 初始 `aria-expanded="false"`，`aria-controls` 指向實際存在的面板。
- Enter 展開，焦點留在原按鈕，面板變為可見。
- Space 收合，焦點仍留在原按鈕，面板隱藏。

「報名資料補充資訊」預設收合。Enter 後可讀到 B2 標記比例與限制文字；Space 後收合並保留焦點。該比例不在 `ops-core-kpis` 內。

## 對比

在圖卡背景 `rgb(247, 249, 252)` 上，以相對亮度計算、並先把半透明色合成到背景後：

- KPI 數字 `rgb(33, 37, 41)`：14.63:1
- 學期說明的 muted 文字 `rgba(33, 37, 41, 0.75)`：6.59:1
- 圖表軸文字：4.70:1

三個取樣都高於一般文字 4.5:1。這不是全頁 WCAG 稽核。軸文字 4.70 接近門檻，但沒有低於門檻，也沒有改共用 chart theme。

## 螢幕閱讀器

本階段沒有啟動 NVDA、JAWS 或 VoiceOver。ARIA 屬性與鍵盤操作已由 Playwright 檢查，不能据此說螢幕閱讀器驗收已完成。
