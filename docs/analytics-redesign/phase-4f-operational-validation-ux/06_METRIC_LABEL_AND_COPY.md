# 指標名稱與說明文案

現有頁面已經避免把這區叫做學習成效，卡片標題也帶有「預約」。下面的候選名稱再把母體寫進標題，避免只剩「出席率」或「預約率」。

| 現有標籤 | 候選標籤 | 為什麼 |
|---|---|---|
| 總預約數 | 預約筆數 | 公式是預約列。現有 hint 已寫筆數，標題可以跟 hint 一致 |
| 預約率 | 預約名額比 | 分子是筆數，分母是名額加總。不是場次有沒有人預約的比例 |
| 簽到出席率（預約） | 預約列簽到率 | 去掉「出席率」這個會被看成學生比例的詞 |
| 違規率（預約） | 預約列違規狀態比 | 分子是預約列上的狀態，不是違規表的事件數 |
| English Pass Rate（API 欄位，頁面未顯示） | 報名資料 B2 標記比例 | 只描述 `hasCEFRB2` 肯定值。不是英語能力達標率 |

不要在正式畫面單獨使用「成效」「達標率」「出席率」「使用率」。這些詞沒有說明母體。

## 必須分開的概念

| 不要混成同一個詞 | 這支總覽實際有的 | 這支總覽沒有的 |
|---|---|---|
| 預約筆數 / 不重複學生數 | 預約筆數 | 學生數。V-OPS-04 之後也只供對照，不進現有 KPI |
| 預約列簽到率 / 學生出席比例 | 已簽到列 ÷ 預約列 | 至少簽到一次的人數 ÷ 有預約的人數 |
| 預約名額比 / 場次利用率 | 筆數 ÷ 名額加總 | 有預約的場次數 ÷ 場次數。後者現在沒有獨立欄位 |
| 違規狀態比 / 違規事件率 | 已登記違規的預約列 ÷ 預約列 | `event_violations` 列數 ÷ 任何母體 |
| 報名 B2 標記 / 測驗達標 | 報名表肯定標記 ÷ 報名列 | 學習歷程或考試分數的達標 |

## 建議放在卡片上的短文案

資源供給：「114-2 活動日 2026-02-01 至 2026-07-31 的場次名額加總。含沒有人預約的場次，也含學生端隱藏的場次。待驗證：隱藏名額佔比。」

預約需求：「仍保留在系統中的預約筆數。學生取消成功後，該筆會從這個數字消失。一人參加多場會計多筆。」

供需：「預約筆數除以名額總數。沒有人預約的場次只出現在分母。」

實際參與：「狀態為已簽到的預約筆數，除以全部預約筆數。未簽到與已登記違規都留在分母。這不是學生出席比例。」

例外：「狀態為已登記違規的預約筆數，除以全部預約筆數。待驗證：與違規紀錄表的筆數是否相同。」

補充區，預設收合：「報名資料裡，114-2 這個學期代碼的 B2 標記有多少被填成肯定。它不代表參加活動之後的英語能力。」

## 空狀態

維持現有句子的意思，並補上單位：「這個活動日區間裡，預約筆數、預約名額比、簽到與違規狀態目前都是 0。」分項載入失敗仍用現有警告，不改成另一個總數。
