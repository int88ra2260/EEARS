# 09 對後續架構的含義

這裡只寫契約已經迫使設計不能做的事。不重提三個方案的比較。

## 應成為共用基礎的能力

這些不是新的分析，是每個分析都缺的同一組欄位。

| 能力 | 為什麼現在必須共用 | 證據 |
|---|---|---|
| Metric ID 隨數字送出 | 五種達標不能靠頁面標題區分 | `03` 的規則表 |
| 母體句 | 名冊、班級、預約列、快照 version、工作集是不同分母 | `01` 的 WHERE |
| 時間契約 ID | 「學期」至少有日期 CAST、日期字串、檔案標籤、名冊、終身嘗試、快照版本 | `04` |
| 缺漏政策 | 缺等級、缺科、沒有第二梯，三種處理不能混成一個「未改善」 | `06` Q4、D6、D8 |
| 來源延遲 | 班級即時、快照非同步、KPI 不讀培力表 | `05` |
| 宣稱等級 | 因果旗標只蓋住 LVA，沒有蓋住「通過率」「認證」 | `07` |

共用的是標籤與字典，不是共用一個 SQL、一個學期參數或一個快照。

## 必須維持不同語意的分析

| 不要合併 | 原因 |
|---|---|
| 預約列出席率 vs 名單參與率 | 單位是列 vs 人，日期解析也不同 |
| 培力四項等級 vs KPI 成對 | 來源表、門檻、分母都不同。D11 未決定前合併會丟掉其中一種業務 |
| 行政培力通過率 vs 班級通過率 | 同一布林，分母一個是出席、一個是註冊 |
| 歷史最佳 vs 成對達標 | 一個是跨工具狀態，一個是同工具成對 |
| 快照成長 vs 名冊成果 | 成長要兩梯；成果目前是終身或四項等級 |
| 微學習 30 日 vs 活動學期 | 窗不同，且不在同一條投影 |
| 有伴分數差 vs 達標率 | 有伴是關聯，而且已有 caveat。放進達標圖會把關聯說成成果 |

未追完的問卷分析、週報、口說、ET 分組仍是獨立用途。沒有證據說它們沒有價值，只有證據說它們不在快照輸入裡。

## 應放棄的設計假設

| 假設 | 為什麼不成立 |
|---|---|
| 學習歷程快照是所有成效的核心 | KPI 與班級頁不讀它。快照母體也不是名冊 |
| 有一個 B2 率可以統一 | 規則 R-FILE 到 R-NEAR 的分母與門檻不同。統一會違反 D1 還沒做的決定 |
| 學期篩選足以對齊 | 日期學期、檔案學期、名冊、終身嘗試不是同一刀 |
| 重建完成等於成績已進 KPI | 重建讀的是事件；KPI 只讀 et。培力 Excel 預設不寫 et |
| `cutoffAt` 是資料截止 | 它沒有過濾來源，只進入版本字串與 `derivedAt` |
| `isB2plus` 或註解裡的 B2+ 代表加號級距 | 正規化已把加號刪掉 |
| `causal_effect` 代表做過因果推論 | 同物件把宣告設為 false |
| 未掛載路由等於相關服務不存在 | `englishTestsRouter` 沒人 require；`rebuildSemesterBestSkills` 仍在 v3 重建流程 |
| CAPS 仍是成長模型 | 只剩遷移註解與分組 GSE 快照 |

## 開始改功能之前必須先有答案的問題

否則實作只會把未決政策寫死。

1. D1：對外那一個句子指哪一個 Metric ID。
2. D2：名冊成果的嘗試範圍。不決定就不要改 `loadAttemptsForStudents`，也不要在標題寫「本學期」。
3. D5：培力聽讀與說寫分日是否仍算同一場。這決定 same_date 能不能當預設。
4. D6：缺資料留在分母還是移出。
5. D11：雙軌是刻意的（場次 vs 名冊）還是事故。刻意則在字典禁止對帳；事故則先對 V-06，再談要不要寫進同一張表。

D3、D7、D8、D9、D10 會影響版本與文案，但不會阻擋「先在 API 加上 Metric ID 與母體句」這種不改數字的標示。標示仍然是實作，不在本階段做。

## 測試契約（以後寫測試時的斷言，現在不寫）

- 同一學號、名冊在 114-1、嘗試日在 114-2：在 lifetime 政策下算通過候選；在學期日期窗下不算。兩種都要有測名，不能只測一種還叫做學期達標。
- `bestep_exam_scores.passed=true` 且沒有 et 列：班級統計算進分子；KPI 不算。
- 同日同工具兩筆 attempt：same_date 合併；same_attempt 分開。
- `B2+` 匯入後等級欄為 `B2`，且 payload 沒有原字串。
- 快照重建兩次在同一天：version 字串相同，第二輪刪除第一輪同版列。
- 微學習請求不讀 `lj_analytic_students`。

這些斷言直接對應已讀程式，用來防止以後重構成「一個達標函式」。
