# 06 資訊架構與工作流

不設計視覺。頁面是責任邊界。既有 URL 在遷移完成前都保留，新工作流先是規格。

## Workflow A — 主任看中心概況

問題：這一季活動辦了沒、名額有沒有被用、有沒有已發布的成果版本。

流程：開啟監測首頁 → 只放 DOM-OPS 五個 ID（Scenario 1）→ 旁邊一塊「最近正式版本」若沒有達標發布則顯示未發布，不顯示 KPI 數字冒充 → 若要人的參與，連結到 DOM-PART，不把列出席率換算成人數。

篩選：日期學期（明確標 Event Time）。沒有達標政策選擇器。

頁面責任：`page.monitor.center`。不擁有班級名單，不擁有成長圖。

導覽：到 B（行政草稿）、到 C（若有待核准）、不到研究頁。

## Workflow B — 行政做培力草稿

問題：這一檔的出席與四項等級，以及（分開的）名冊成對監測值，能不能送進草稿。

流程：選擇檔案學期 → 看 `bestep.file.four_skill_cefr_b2` 與出席明細 → 系統顯示缺等級人數（即使現況把他們算未通過）→ 另一區選擇名冊學期與**既有**政策鍵，顯示成對監測值，標題含 lifetime 或該政策的時間窗 → 兩區不能拖進同一張圖 → 送出的是草稿包，不是發布。

篩選：檔案學期、班級、政策鍵、工作集。工作集改變分母時，草稿封面寫人數。

頁面責任：`page.draft.bestep` 與 `page.draft.roster` 兩區。D4 未核准前不提供「依考試日重算四項達標率」的按鈕；考試日只可篩出席明細。

導覽：到 C 時，若草稿含達標 ID 且 D1 未核准，送審按鈕不可用，並說明原因。營運數字仍可另送。

## Workflow C — 學期正式發布

問題：要凍結哪一組已核准的指標、截止聲明是什麼、誰核准。

流程：從草稿選 ID → 系統刪掉未核准的達標 ID → 產生 Source Manifest 與 Population Manifest → `in_review` → 第二人核准 → `published`。之後匯入不改變該 Run。

篩選：Reporting Period 是標籤；真正邊界是該 ID 的契約加上 Data As Of 聲明。

頁面責任：`page.publish`。不計算新公式。

導覽：回 A 的「最近正式版本」。舊版清單可讀。

## Workflow D — 教師看班

問題：這個班的人有沒有來、培力檔的四項等級、誰接近 B2。

流程：進入班級 → 參與用名單契約（DOM-PART）→ 培力用檔案學期與 `passed` 的既有卡片，標題改為契約上的顯示名（實作階段才改字，本規格先定文案責任）→ 接近 B2 用快照，並寫 snapshot version。

篩選：班級、檔案學期。沒有全中心政策。

頁面責任：沿用班級 BESTEP 與教師範圍。權限縮小必須出現在頁首，這是規格，不是新圖。

導覽：不進發布，不進資源效果。

## Workflow E — 研究成長

問題：這群人裡，同一工具的前後梯差多少，樣本掉了多少。

流程：選快照版本 → 選工具 → 系統先回覆蓋（幾人有兩梯）→ 才顯示 `snapshot.gse_raw_delta` → 校正值在下一折，預設收合，帶 adjusted 天花板 → 有伴差距在別頁，帶既有 caveat。

篩選：snapshot version、instrument、系所、工作集。沒有「學期」一個字同時代表檔案學期與梯次。

頁面責任：`page.explore.growth`、`page.explore.contrast`。

導覽：可把人送進工作集，工作集回到 B 或 D 時必須被看見。不可把探索率送進 C。

## 頁面與領域

| 頁面責任 | 領域 | 不負責 |
|---|---|---|
| `page.monitor.center` | OPS | 達標、成長 |
| `page.draft.bestep` | ATTAIN 檔案＋PART 出席 | 名冊成對 |
| `page.draft.roster` | ATTAIN 成對 | 培力檔、歷史最佳 |
| `page.state.best` | STATE | 正式成果 |
| `page.publish` | GOV | 新算法 |

既有學習成效選單（上呈、找人、看資源、比較）在 WP 完成前保持原樣。新頁面責任是遷移目標，不是現在就改路由。

## 篩選器規則

每個篩選器有類型：`eventSemester`、`fileSemester`、`rosterSemester`、`asOf`、`snapshotVersion`、`policyKey`、`instrument`、`workingSet`。禁止一個名為「學期」的控制項把值同時送到 OPS 與 KPI。若畫面為了少一個下拉而只放一個學期字串，必須在 Query Context 裡複製成多個具名 bound，並在它們語意不同時顯示警告。114-2 這個字可以同時是檔案標籤與名冊 id，但仍然是兩個欄位。
