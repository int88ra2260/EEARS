# 成長與非因果限制

資源頁的短句與展開說明都寫：資源覆蓋是描述性關聯，不代表該資源造成能力提升。若 API 每一列的 `interpretation` 相同，展開區會原文顯示那一句。列上的 `causalClaimAllowed` 不是 true 時，使用非因果句子。即使將來有一列沒有關閉因果旗標，畫面仍不把它寫成教學效果。

準因果、傾向分數與 AIPW 陣列仍由 API 回傳，資源頁不畫、不改名、也不提升證據等級。

技能成長頁原有「這些都是觀察，不代表課程造成進步」。這次在「比預期多多少」補上：這是探索性估計，不是因果證明；不同英檢的 CEFR 不能當成完全可交換。詞彙說明 `LA_TERM_HELP.adjustedGrowth` 同步寫明探索性與非因果。

`lvaAdjustedGrowthService` 與預期成長公式沒有修改。頁面不假設每一筆都有完整前後測；沒有資料時技能頁仍走既有的空狀態。
