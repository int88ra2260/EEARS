# 證據品質

資源列的「資料夠不夠」仍用既有 `EvidenceQualityBadge`，等級來自該列的 `evidenceLevel`。目前彙總會給 `descriptive_medium` 或 `descriptive_low`，徽章文案仍是既有的「尚可」或「資料較少」。顏色不是唯一提示，徽章有文字。

沒有新增另一套 High／Medium／Low 分數。沒有讀 Shadow 日誌，也沒有把離線契約檢查顯示成正式資料驗證。

資源 API 沒有排除原因明細。展開說明直接寫這件事，並請管理者到既有技能成長或原始資料頁看那邊已有的欄位。頁面不補造排除原因。

三個 Analytics Shadow 預設仍關閉。Hub 既有句子「三個 Shadow 預設關閉。此頁沒有即時診斷結果。」保留。
