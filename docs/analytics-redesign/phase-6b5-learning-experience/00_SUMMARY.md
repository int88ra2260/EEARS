# 本次改善

管理者可以從成效分析中心的「學習參與與歷程」進入既有的資源覆蓋頁，看不重複學生數與可觀察事件次數，展開資料限制，再打開既有的技能成長、課／師／活動或原始資料頁。

資源覆蓋頁現在直接寫明：

- 參加人數是不重複學生，不是事件次數。
- 沒有列只表示這份快照沒有可用紀錄，不能推論沒有學習。
- `0` 顯示 0；空值顯示 —，不改寫成未觀察。
- 匿名軌跡不會被配成某一位學生的姓名。
- 資源覆蓋是描述性關聯，不代表該資源造成能力提升。
- 「資料夠不夠」沿用 API 的 `evidenceLevel`，不是新的品質分數，也不是 Shadow 即時報告。

`GET /api/admin/learning-analytics/resources` 回傳的準因果估計沒有畫出來。這支回應沒有排除原因明細，頁面會這樣說，並把人帶到既有的技能成長或原始資料頁。篩選不會自動帶過去。

技能成長頁既有的「比預期多多少」補上探索性、非因果、不同英檢 CEFR 不能當成完全可交換。校正後進步的公式沒有重算。

本提交收斂學習參與的讀法與證據限制。基準是 Phase 6B.4 commit `07375a0dc13d61b9942927a1d67de13bd9e742cc`。
