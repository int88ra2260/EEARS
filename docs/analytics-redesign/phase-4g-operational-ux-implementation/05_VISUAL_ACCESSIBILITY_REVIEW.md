# 視覺、響應式與無障礙檢查

## 已在元件測試確認

- 指標說明是 `<button type="button">`，能取得焦點，並有 `aria-expanded` 與 `aria-controls`。
- 載入狀態使用 `role="status"`。
- API 錯誤使用 Bootstrap `Alert`。
- 卡片欄位有 `col-12`，窄容器時會整列堆疊。學期選單寬度是 100%，上限 220px。
- 第一屏說明預設收合，不擋重新整理與學期選單。

## 未在瀏覽器確認

本機 `127.0.0.1:3001` 與 `127.0.0.1:3000` 都沒有在聽。沒有可用的管理端登入階段，也沒有為了這一階段另起伺服器或安裝瀏覽器測試框架。

因此以下項目**沒有完成視覺驗收**：

- Desktop、tablet、mobile 的實際排列與是否溢出。
- 真實圖表尺寸、長條圖標籤是否重疊。
- 場次表 sticky 表頭在捲動時的位置。
- 說明展開後是否遮住按鈕。
- 顏色對比、螢幕報讀，以及按鈕在真實瀏覽器按 Enter 或空白鍵。
- 切換學期、載入、空資料、錯誤在畫面上的實際樣子。

jsdom 的欄位 class 不能代替這些檢查。
