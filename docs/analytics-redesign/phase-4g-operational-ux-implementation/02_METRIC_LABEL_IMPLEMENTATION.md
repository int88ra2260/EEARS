# 指標名稱與說明

文案在 `activityOpsPresentation.js`。畫面只格式化 API 數字，不重算比率。缺值是「—」。百分比沿用原本的一位小數。

| API 欄位 | 畫面名稱 | 出現位置 | 說明要點 |
|---|---|---|---|
| `totalEventCapacity` | 活動總名額 | 資源供給 | 名額加總，不是場次數。含零預約與學生端隱藏場次。 |
| `totalReservations` | 預約筆數 | 預約需求 | 仍在表上的預約列。取消成功會刪列，所以不是累計預約總次數，也不是不重複學生數。 |
| `bookingRate` | 預約名額比 | 預約需求 | 預約筆數 ÷ 活動總名額。分母含沒有人預約的場次。隱藏場次佔比待資料驗證。 |
| `attendanceRate` | 預約列簽到率 | 簽到與使用 | 已簽到預約列 ÷ 全部預約列。不是學生出席率或學習參與率。 |
| `violationRate` | 預約列違規狀態比 | 行政例外 | 已登記違規的預約列 ÷ 全部預約列。不是 `event_violations` 的事件比例。兩邊是否一致待資料驗證。 |
| `englishPassRate` | 報名資料 B2 標記比例 | 收合的報名補充區 | 報名表 B2 標記。時間是報名學期標籤。沒有與預約 JOIN。不能解讀成活動提升英語能力。 |

營運指標的母體句是「全中心活動，以活動日期篩選。」時間欄位寫的是活動日期（`events.date`）。

活動日期顯示把 `SEMESTER_RANGES` 的 `YYYY-MM-DD` 轉成 `YYYY/MM/DD–YYYY/MM/DD`。114-2 因此顯示 `2026/02/01–2026/07/31`，來源是既有設定，不是頁面裡的第二份對照表。設定裡沒有的學期只顯示「此學期尚未列入共用日期設定」。

報名補充區另外寫明它不使用上述活動日期。

每個營運卡片有「說明」按鈕，`aria-expanded` 與 `aria-controls` 可讓鍵盤與輔助技術打開定義、母體、計算與限制。第一屏不把這些段落全部展開。

待資料驗證的句子留在說明裡，沒有把這些數字標成正式成果。
