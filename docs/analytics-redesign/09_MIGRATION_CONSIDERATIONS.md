# 09 遷移考量

本文只排列順序與風險。沒有改程式。沒有資料修復步驟。

## 原則

先凍結對外句子，再改查詢範圍，最後才考慮拆表或併頁。每一步都要能對回 `08` 的指標 id。數字會變的步驟（收斂 KPI 嘗試範圍）單獨做，並在變更前用 V-01 的查詢告訴主任差多少。該查詢仍須人工同意。

## 階段

### M0 盤點凍結（現在）

維持現有 API。文件以本目錄為準。不刪未掛載路由，避免誤傷未搜完的腳本。

完成標準：主任知道目前至少有「四項等級」「成對門檻」「歷史最佳」三種說法。

### M1 命名與標示（不改計算）

- 總覽與歷程 API 的 note 不再寫「B2+」，改為與 rank≥4 一致的「達 B2」（F-11）。這是文案，仍會讓舊簡報對不上，需要一句話說明加號已在匯入時移除。
- 班級頁通過率顯示名改為四項等級，避免與 KPI 同名。
- 快照頁標題帶 `snapshot_version`。
- 活動分析在 scope 縮小時顯示母體句（F-09，標示完整度目前 PARTIAL，實作時要再核對每個圖）。
- 模型執行、洞察等已改導的入口，確認沒有殘留按鈕指向舊解釋。`LearningAnalyticsModelRunPanel.jsx` 前期已見連結，M1 要再點一次。

風險：低。使用者會發現「以前那個 B2+」不見了。這是預期，不是回歸。

測試：文案與 note 的單元測試；不需要資料庫。

### M2 官方達標的時間範圍（會改數字）

只動 `roster.pair_pass`。在政策或報表參數明確選擇之前，不把「全部 valid 嘗試」繼續叫做本學期成果。

可選規則（實作時二選一，本文件不代決）：

- 嘗試的 `testDate` 落在該名冊學期的 `SEMESTER_RANGES`。
- 或指定一次匯入批次／考試日。

未選規則前不要改查詢。選了之後用 V-01 對一個學期估差，再改 `loadAttemptsForStudents` 的條件。

歷史最佳（S5）不在這一步改成官方達標。它改為 as-of 報表，或留在對照／稽核，避免兩條官方線。

風險：中高。補考、跨學期最好成績會從「本學期達標」消失。那是修正，不是資料遺失；舊定義若仍要，留成對照指標 id，不刪歷史函式直到報表改完。

### M3 入口重組（計算已穩定之後）

依 `08` 把現有路由掛到三個入口。可以先只改導覽與頁首說明，路由路徑暫留，以免書籤全斷。

不要在 M2 之前把 KPI 放進「本季營運」。

### M4 對照入口

把有伴 outcome、技能前後梯、資源樣本搬進同一組說明：窗、工具、樣本流失、非因果。`causal_effect` 不進任何預設畫面。V-05 確認旗標後再決定欄位是否只留內部表。

### M5 追溯與重建狀態

班級／KPI（來源表）與快照頁並陳時，顯示快照時間與最近匯入時間的關係。這一步依賴 V-03，且依賴讀懂重建服務（目前 PARTIAL）。不要在沒讀完 `analyticRebuildService` 前做「自動重建」。

### 明確不做

- 不為了架構重寫學習歷程表。
- 不把未掛載的 `englishTestsRouter` 掛回去湊跨學期圖。
- 不在遷移中實作簡報大題分數，除非另有欄位設計與原始檔。
- 不合併班級頁與 KPI 頁。兩者使用者與分母都還不同；合併會弄丟班級作業。
- 不自動改正式庫、不跑會寫入的匯入。

## 回滾

M1 回滾是還原文案。M2 回滾必須保留舊查詢路徑一個學期，否則主任無法解釋數字為何變了。M3 回滾是導覽。M4／M5 不刪原 API。

## 測試策略

| 階段 | 測什麼 |
|---|---|
| M1 | note、頁首、禁止出現「因果」於預設學習成效首屏 |
| M2 | 固定學號：名冊學期內一筆、學期外一筆，只有範圍內的計入官方 |
| M3 | 同一路由仍回傳 M2 的契約 |
| M4 | 有伴 outcome 的 caveat 仍在；對照頁沒有入口 2 的達標率 |
| M5 | 快照版本與空資料的頁面不顯示假的學期達標 |

既有業務規則（預約截止、黑名單、問卷 Gate、學生須登入才看個人資料）不在這次遷移範圍。分析頁若讀個人成績，仍須走現有權限，不得為了對照入口放寬。
