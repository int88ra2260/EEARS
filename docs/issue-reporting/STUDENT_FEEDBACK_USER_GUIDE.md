# 學生回報使用說明

這份說明給英語中心同仁與學生使用。不需要會寫程式。

學生從「我的帳號」把問題或建議送給中心。中心在後台查看、指派、回覆和結案。內容只給中心看，不會公開給其他學生。目前不能附加檔案。

## 誰可以使用

學生要先登入，並完成信箱驗證。沒有驗證前，頁面上只會提示先完成驗證，不能送出。

中心人員要有「學生回報」權限才能看到後台選單。有「學生回報（處理）」的人可以回覆、指派、改優先級、寫內部備註和結案。只有查看權限的人看得到內容，但不能處理；詳細內容下方會寫「你目前可以查看，不能回覆、指派或結案。」

## 學生：如何送出

1. 登入後打開「我的帳號」。
2. 找到「遇到問題」。它預設是收合的，點開後才看得到表單。
3. 選類型：
   - 問題回報：系統用不了、預約或資料有錯。
   - 建議／許願：希望新增或調整功能。
4. 選項目：預約或取消、問卷、帳號或信箱、培力報名、學習歷程、介面顯示、其他。
5. 寫下發生了什麼，或想許的願。最多 2000 字。
6. 「希望中心回覆」預設是勾著的。勾著時，中心結案前會先寫一則學生看得到的回覆。取消勾選時，中心仍會看到，但不一定個別回覆。
7. 按「送到中心」。

學號、姓名和信箱會自動帶入，不用自己重填。急件請在上班時間（週一至週五 09:00–17:00）打 07-5252000 分機 5808 或 5876，不要只靠這個表單。

## 學生：如何看回覆和補充

表單下方有「我送出的」。點一筆可以看自己寫的內容，以及中心寫給你的回覆。看不到中心的內部備註。

若還要補充，在「補充說明」寫完後按「補充」。已結案的案件如果又補充，會回到「處理中」。

## 中心：從哪裡進入

用中心帳號登入後台，打開「內容與公告」，再點「學生回報」。

網址是：`/admin/student-feedback`

## 中心：頁面上有什麼

上方四個數字是全部案件的統計：全部、待處理、處理中、已結案。這四個數字不受下面的篩選影響。

狀態只有三種：

| 狀態 | 意思 |
|------|------|
| 待處理 | 新進來，還沒有人接手 |
| 處理中 | 已經有人指派、回覆，或學生又補充了 |
| 已結案 | 這件先告一段落 |

優先級是處理順序，不是問題嚴重度：

| 優先級 | 意思 |
|--------|------|
| 未設定 | 還沒排。以前的舊案件會停在這裡，這是正常的 |
| P0（最優先） | 先處理 |
| P1（高） | |
| P2（中） | |
| P3（低） | 可以稍後 |

搜尋可以打學號、姓名或內容。也可以用狀態、項目、優先級、承辦人、日期來縮小列表。改完條件後按「搜尋」。排序可以依提交時間、更新時間、案件編號或優先級。

點列表中的一列，下方才會出現這筆的詳細內容。若先看到「載入這筆回報」，等它消失再操作。還沒載入完成時，系統不會讓你改到別的案件。

## 中心：建議的處理順序

1. 看學生希望得到回覆，還是不要求個別回覆。
2. 需要同事接手時，選承辦人後按「指派」。原本是待處理的案件，指派後會變成處理中。
3. 需要排先後時，選優先級後按「更新優先級」。只改優先級不會改變狀態。
4. 要讓學生看到的話，寫在「回覆學生」，再按「送出回覆」。這則回覆會出現在學生的「我送出的」。
5. 只給中心同事看的判斷，寫在「內部備註」，再按「記下備註」。學生看不到。
6. 處理完按「結案」。

學生有勾「希望中心回覆」時，必須先有一則學生看得到的回覆，才能結案。否則系統會提示先寫回覆。

結錯了可以按「改回處理中」。沒有辦法改回「待處理」。

「處理歷程」會留下狀態、承辦人和優先級的變更，包含誰在什麼時候改的。它不存放備註正文。

回覆學生時，系統會寄通知信。若那則回覆旁邊出現「通知信沒有寄出」，代表信沒送到，但回覆仍留在案件裡。請改用其他方式和學生聯絡，不必為了信沒寄出而把案件刪掉。

## 請不要這樣做

- 不要把內部討論寫進「回覆學生」。
- 不要在真實學生案件上試按結案或改優先級。
- 不要把案件內容轉貼到公開群組。
- 列表上方的統計和篩選後的筆數不一樣時，先看是不是已經下了搜尋條件。
